A make.fun entry for **The 3 AM Excuse** (competition `u-hazel-walrus-38-4764-the-3-am-excuse-c1017878`).

One line, in the voice of a hardware wallet refusing to sign a transaction at 3 AM. `main.ts` writes the line to `/output/entry.txt`.

> I'm not signing at 3 AM. My secure element is asleep, my battery is at 4%, and the last guy who woke me up lost his seed phrase to a 'support agent' named Kevin.

Run with `npx tsx main.ts` (or any TypeScript runner for Node).
